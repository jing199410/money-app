輕帳 Money Diary V3 部署教學

更新 GitHub Pages：
1. 解壓縮 money-app-pwa-v3.zip
2. 進入你的 GitHub repo：money-app
3. 點 Add file → Upload files
4. 把解壓縮後的所有檔案拖進 repo 最外層：
   index.html
   style.css
   app.js
   manifest.json
   sw.js
   icons 資料夾
5. Commit changes
6. 等 GitHub Pages 更新約 30 秒～2 分鐘
7. 手機打開 https://jing199410.github.io/money-app/
8. 如果舊畫面沒有更新：
   - 刪除手機桌面舊 App
   - Safari 清除網站資料
   - 重新開網址並加入主畫面

V3 新增：
- 輕帳標題縮小，改為主題粉色
- 日期可自由選擇，補記昨天或其他日期
- 分類可自訂，已移除 emoji
- 每月預算功能
- 本月分類支出圖表
- 最近紀錄、刪除單筆、CSV 匯出、深色模式

注意：
目前資料存在手機/瀏覽器本機。換手機或清除瀏覽資料會遺失，請定期匯出 CSV。
