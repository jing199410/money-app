輕帳 V4.5 修正版部署教學

這版修復：「加入手機主畫面後打開變成 app.js 程式碼」的問題。

更新方式：
1. 解壓縮此 zip。
2. 到 GitHub 的 money-app repo。
3. 把 zip 裡所有檔案全部上傳到 repo 最外層並覆蓋。
4. 等 GitHub Pages 重新部署完成。
5. iPhone 上請先刪除舊的桌面 App。
6. 用 Safari 開啟：https://jing199410.github.io/money-app/?v=4.5
7. 分享 → 加入主畫面。

如果仍看到程式碼：
設定 → Safari → 進階 → 網站資料 → 搜尋 github.io 或 jing199410.github.io → 刪除。
再重新開 Safari 加入主畫面。

更新前建議先匯出 JSON 備份。
