輕帳 PWA V4 部署教學

更新方式：
1. 解壓縮 money-app-pwa-v4.zip
2. 打開 GitHub 的 money-app 專案
3. 將解壓縮後的所有檔案上傳到 repo 最外層
   - index.html
   - style.css
   - app.js
   - manifest.json
   - sw.js
   - icons 資料夾
4. Commit changes
5. 等 GitHub Pages 更新約 30 秒～2 分鐘
6. 手機 App 關掉重開；若還是舊版，刪除桌面 App 後重新加入主畫面

V4 更新內容：
- 全站黑色改為深灰階，視覺更柔和
- 新增可愛貓咪 App icon
- 首頁新增今日支出
- 分類預算顯示修正
- 預算超支提醒
- 最近紀錄支援編輯與刪除
- 新增 JSON 備份匯出與匯入
- 保留 CSV 匯出，也支援匯入 CSV

重要提醒：
此版本是單機版，資料存在目前手機/瀏覽器中。
請定期到「設定 → 匯出備份」下載 JSON 備份。
換手機或重裝 App 時，請用「匯入」還原資料。
